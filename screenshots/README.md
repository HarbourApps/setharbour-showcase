# Screenshots

Screens from the SetHarbour portfolio edition. These are captures of the
SetHarbour experience; the portfolio app reproduces the same visual identity
and behaviour from synthetic data.

| File | Shows |
|------|-------|
| `home-dashboard.png` | Populated home dashboard — greeting, LED ticker, weekly stats, activity chart, latest workout, "Start a workout". |
| `animated-status-ticker.png` | The animated LED-style status ticker (dark panel, gold border glow, coloured indicator). |
| `plans-folder-and-list.png` | Dual-view plan browser — folder view and list view with filters. |
| `exercise-input-validation.png` | Exercise logger with the custom keypad and the three-digit "Superman" validation banner. |
| `interval-workflow.png` | Interval training flow — explainer, plan list and active timer. |
| `progress-dashboard.png` | Progress & statistics — weekly frequency, personal bests, muscle focus, all-time stats. |
| `smart-history-insights.png` | Deterministic session summaries (controlled / demanding / challenging classifications). |
| `backup-and-privacy.png` | Import / export settings and the privacy-first messaging. |
| `exercise-library.png` | Exercise library landing screen — presets, custom exercises, guides. |
